 Harshita Khandelwal - Portfolio

A portfolio showcasing my skills , projects , certificats and experience . Built using React.js , Express. js for backend and mongoDb for database it is an nono SQL database.

---

 Live Demo

https://portfolio-ruby-pi-g3svsesevc.vercel.app/

---

 Features

-  Responsive modern UI
- Dark/Light theme toggle
- Projects showcase
- Certifications section
- About me section
- Contact form
-  Smooth animations using AOS

---
 Tech Stack

### Frontend
- React.js
- Vite
- CSS
- React Icons

### Backend
- Node.js
- Express.js
